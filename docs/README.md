## Правила документации

- Документация — часть исходников: на неё действуют те же проверки гигиены
  (tests/source-hygiene.test.js), что и на код: только LF, без посторонних
  письменностей, без смешения кириллицы и латиницы внутри одного слова.
- Правило проекта для кода действует и здесь: одно правило — одно место. Если
  поведение описано в двух документах, один обязан ссылаться на другой, а не
  пересказывать.
- Описание не должно разъезжаться с кодом: при изменении поведения правьте
  документ в том же коммите.
